# ServoErrorAnalyzer

伺服轴误差分析工具:读取 CSV 数据文件,可视化各轴位置/速度误差、计算响应延迟统计,
并提供双轴联动切圆的真圆度 / 方向尺寸 / 换向毛刺分析。

---

## 功能

### 主窗口(AKD 示波器式画布)
- 加载伺服数据 CSV 文件(支持拖拽)
- 各轴**位置误差 + 速度指令 + 速度反馈**同屏显示,
  左侧双 Y 轴(外侧速度刻度 / 内侧位置误差刻度),顶部横排图例;
  三类曲线可独立开关;静态层缓存 + 可见区间裁剪
- 鼠标游标:悬停查看任意时刻各轴误差/速度值与该点响应详情
- 框选缩放 / 右键复位 / Ctrl+滚轮缩放;切换轴可见性时保留用户缩放视野
- 右侧面板:每轴**全程统计**(平均/最大/中位/标准差响应、无响应点数、
  最大|误差|、RMS 误差)+ 光标点详情

### 方向分析对话框(真圆度)
- 指令轨迹**最小二乘圆拟合(LSC)**作为基准圆,自动剔除进刀/退刀段
- 真圆度按反馈轨迹 LSC 圆心评定(最大−最小半径)
- **径向误差放大**显示(×1 ~ ×500,圆度仪式),非圆轨迹自动回退
- **换向毛刺检测**:指令速度过零点(无速度列时用位置差分)附近的
  径向轮廓偏差峰值,逐点标注 + 最大值指标卡
- 四方向(X / Y / 两对角线)卡尺尺寸:指令尺寸、反馈尺寸、尺寸偏差
- 指标卡:真圆度、平均半径、半径范围、最大换向毛刺

## CSV 格式

支持两种格式:

**标准格式**(推荐)— 列名符合 `axes.mach.<l|f>.<p|v>[<轴名>]` 规则:

```
TIME, axes.mach.l.p[X], axes.mach.f.p[X], axes.mach.l.v[X], axes.mach.f.v[X], ...
```

- `l` = 指令(command),`f` = 反馈(feedback)
- `p` = 位置,`v` = 速度(速度列可选;齐全时启用速度误差模式与换向检测)
- 时间列:`TIME` 或 `FINISHED`

**兼容格式** — 固定 8 列 X/Y/C 结构:

```
FINISHED, time, xCmd, yCmd, cCmd, xFb, yFb, cFb
```

第二行可选填写单位(如 `units,sec,mm,...`),解析时自动跳过;
UTF-8 BOM 自动剔除。

## 构建

依赖:Qt 5.12+ 或 Qt 6(含 Widgets 模块)。源码为 UTF-8 中文字面量,
MinGW/GCC 直接编译,MSVC 由工程文件自动附加 `/utf-8`。

```bash
cd ServoErrorAnalyzer
qmake ServoErrorAnalyzer.pro
mingw32-make release      # 或 make
```

或用 CMake:

```bash
cmake -B build
cmake --build build
```

### 测试

`test/` 下的离屏测试程序用**已知真值的合成数据**(连续积分仿真一阶位置环)
验证圆分析(拟合半径、进退刀剔除、弧度覆盖、半径收缩量),并对真实 CSV
做解析、统计、圆拟合与渲染的全链路回归。退出码 = 失败断言数:

```bash
cd ServoErrorAnalyzer/test
qmake test.pro && mingw32-make release
QT_QPA_PLATFORM=offscreen ./release/test_analysis "../../Dump 260604 163301.csv"
```

## 实现说明

- 响应延迟:对每个指令运动采样点,在前向窗口内寻找反馈首次同向到达
  指令值的时刻;未到达记为 NaN(面板显示"—(未到达)"),不再与
  瞬时响应 0 混淆。统计仅覆盖运动段。
- 真圆度:指令轨迹双初值(包围盒/中位数)三遍迭代 Kasa LSC 拟合剔除
  进退刀段;若拟合失败(非圆轨迹)回退为包围盒中心 + 全部采样,
  换向毛刺与收缩法指标自动禁用。
- 换向毛刺:指令速度过零点 ±5° 弧段内,反馈对**反馈自身 LSC 圆**的
  最大径向偏差(消除圆心偏移/尺寸误差影响,与球杆仪习惯一致);
  圆心偏移、尺寸偏差为独立指标。
- 圆分析核心在 `circle_analysis.h/.cpp`(纯计算,无 UI),
  真圆度图直接使用该实现。
- 方向颜色 / 角度 / 文案统一定义于 `direction_defs.h`。
